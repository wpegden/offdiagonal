\begin{definition}
Let \(v=(x_0,\ldots,x_{k-1})\) be a star-product path, and let
\(v_{\le i}\) denote its prefix of length \(i\) for \(0\le i\le k\).  For
\(\ell\in\{0,\ldots,t\}\), define
\[
  U_\ell(i)=|U_\ell^{v_{\le i}}|,
\]
where \(U_\ell^p\) is the rank-at-most set of
\(\noderef{StarProductRankAtMostSet}\).  For indices outside
\(\{0,\ldots,k\}\), the formal value is set to \(0\).
\end{definition}
