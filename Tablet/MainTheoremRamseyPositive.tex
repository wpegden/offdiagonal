\begin{helper}
For all integers \(s,k\ge1\), the Ramsey number \(r(s,k)\) is positive.
\end{helper}
\begin{proof}
Consider the empty graph on the empty vertex set.  Since the vertex set is
empty, it contains no clique of size \(s\ge1\), and its complement contains
no clique of size \(k\ge1\).  Therefore
\(\noderef{RamseyNumberLowerBoundFromCounterexample}\) applied to this empty
graph gives
\[
  0<r(s,k).
\]
\end{proof}
