\begin{definition}
Let \(G\) be a loop graph on a vertex set \(V\).  The star product digraph
\(D^*(G)\) has vertex set
\[
  V(D^*(G))=\{(a,b)\in V^2: ab\in E(G)\}.
\]
There is an arc from \((a,b)\) to \((a',b')\) precisely when
\[
  ab'\in E(G) \quad\text{and}\quad a'b\notin E(G).
\]
For \(G=G(t,q)\), this is the digraph denoted \(D^*(t,q)\) in the paper.
\end{definition}
