\begin{definition}
For the polarity graph \(G(t,K)\), define the concrete star-product marking
rule as follows.  For a prefix \(p\) and a child candidate \(x=(a,b)\), put
\(r=r^p(b)\).  If \(r\le t\), mark \(x\) exactly when \(x\) is popular in
the sense of \(\noderef{StarProductPopularChild}\) or poor in the sense of
\(\noderef{StarProductPoorChild}\).  If \(r>t\), the rule does not mark the
child.  Thus the Boolean value is true precisely for popular or poor
children in the rank range relevant to the paper.
\end{definition}
