\begin{definition}
For a prefix \(p\) and an integer \(r\ge0\), define
\[
  \ell_r^p
\]
to be an index \(\ell\in\{0,\ldots,r\}\) for which the cardinality
\(|Z_\ell^p|\), with \(Z_\ell^p\) as in \(\noderef{StarProductRankLayer}\),
is maximal among the finitely many cardinalities
\[
  |Z_0^p|,\ |Z_1^p|,\ \ldots,\ |Z_r^p|.
\]
The choice is made by finite maximization over the set
\(\{0,\ldots,r\}\).
\end{definition}
